# Wiki: схема и правила для LLM

База знаний лендинга AXIS. Язык страниц — русский, имена файлов — английский kebab-case.
Совместима с Obsidian: связи через `[[wikilinks]]`, теги во frontmatter.

## Структура

```
wiki/
├── CLAUDE.md      # этот файл
├── index.md       # каталог страниц по типам
├── log.md         # хронология операций
├── raw/assets/    # неизменяемые источники (скриншоты, выгрузки)
└── pages/
    ├── entities/  # конкретные части системы: секции, данные, компоненты
    ├── concepts/  # архитектура, i18n, дизайн-система, подводные камни
    ├── sources/   # саммари источников (аудит живого сайта и т. п.)
    └── analyses/  # решения и их причины
```

## Frontmatter (на каждой странице)

```yaml
---
title: Название
type: entity | concept | source | analysis
tags: [тег]
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: [пути или URL]
---
```

`updated:` поднимать при каждой правке. Даты только абсолютные.

## Правила

- При вопросе о проекте сначала `index.md`, потом нужные страницы, потом код.
- Изменили архитектуру, данные, интеграции — обновить страницы, `index.md` (если новая страница) и `log.md`.
- Не писать: git-историю, точные строки кода, TODO текущей задачи, секреты.
- Каждая страница должна иметь входящую ссылку минимум из `index.md`.
