# Дизайн-система «Чертёж»

Страница подаётся как набор листов архитектурного чертежа: AXIS — «ось», компания проектирует кабинеты.
Это ответ на первую версию, которая выглядела шаблонной (см. [[redesign-decisions]]).

## Токены (`app/globals.css`)

| Токен | Значение | Роль |
|---|---|---|
| `--ink` | #0b1220 | текст, рамки листа, тёмный финальный блок |
| `--ink-2` / `--ink-muted` / `--ink-faint` | #3a4352 / #5b6472 / #646d7b | вторичный текст и подписи; `ink-faint` — самый светлый серый, который ещё держит 4,5:1 на paper и brand-soft. Светлее для текста не делать, прозрачность (`/40`, `opacity-50`) тоже — это проверяет `e2e/a11y.spec.ts` |
| `--brand` | #3059df | единственный цвет: точка, выноски, активные элементы |
| `--brand-light` | #9db4f5 | синий на тёмном |
| `--ok` | #15803d | только статус «есть» в инструменте [[order70-tool]] |
| `--paper` / `--surface` | #f4f5f7 / #ffffff | бумага и белые листы |
| `--line` / `--line-strong` | #d3d8df / #b4bcc7 | линии 1px |

Радиусы везде 0. Шрифты: Geist (текст), Geist Mono (аннотации), оба с полным казахским алфавитом.
z-index: шапка 40, плавающий WhatsApp 30, мобильное меню 50, skip-link 60, интро 70.

## Приёмы листа

- Линейка колонок A–L над шапкой (`SheetRuler`), видимые колонки на первом экране (`bg-columns`).
- `SheetHeading`: крупный заголовок строками (`Lines`) слева, метка «Лист NN» и лид справа.
- `Stamp`: штамп чертежа (Объект / Стадия / Проект / Лист) на первом экране и в футере.
- Сетки с линиями через `gap-px` на фоне `bg-line` (этапы, факты, бренды, справочник).
- Моноширинные коды кабинетов (INF, ART, …) и счётчики.

## Движение

- Первый экран проявляется CSS-анимацией (`reveal`, `draw`), без ожидания JS; пока идёт интро — на паузе.
- Интро «Синька» — [[blueprint-intro]]; сборка класса при прокрутке — [[process-illustration]].
- Всё уважает `prefers-reduced-motion`; анимируются только transform, opacity, `stroke-dashoffset`.

## Что убрано из v1 и почему

Светящаяся рамка (BorderBeam), бегущая лента логотипов (Marquee), мигающая сетка (AnimatedGridPattern),
появление каждого блока через blur (BlurFade), счётчики (NumberTicker), заголовки «чёрная половина + синяя половина»,
скругления 20px и затемнения поверх фото — набор приёмов, по которому v1 читалась как шаблон.
