# Интро «Синька»

Один из пяти видов интро (см. [[intro-rotation]]), «родной» для v1. Захватывает внимание на первом визите,
как интро референса [[2026-10-22-screening-reference]]:
синий чертёж «проявляется» в настоящий класс и садится в лист первого экрана.

## Сценарий

| Время | Что происходит |
|---|---|
| 0–0.6 с | синий экран с сеткой, знак логотипа (уголок и квадрат) |
| 0.6–1.4 с | из уголка вытягиваются оси X и Y, подпись «Каждый кабинет начинается с оси» |
| 1.4–2.6 с | белыми линиями рисуются пол, стены, окна, размеры, затем контур мебели |
| 2.6–3.4 с | фон из синего в цвет бумаги, контуры сменяются цветными слоями, загораются экраны |
| 3.4–4.4 с | класс перелетает в `[data-intro-target]` первого экрана, оверлей исчезает |

## Как устроено

1. `IntroBoot` — inline-скрипт первым элементом `<body>`: решает, играть ли, и ставит `html[data-intro="play"]`
   до первой отрисовки; через 4,4 с снимает атрибут сам (страховка, если JS не загрузился): ровно когда
   заканчивается CSS-выход оверлея (4,0 → 4,4 с), чтобы первый экран не стоял пустым.
2. Таймлайн — CSS (`app/styles/intro.css`), поэтому стартует до гидрации. Разметка — `scenes/blueprint-scene.tsx`.
3. `IntroStage` (общий контроллер всех видов) после гидрации берёт интро на себя: снимает таймер загрузчика
   (`window.__axisIntroTimer`), отключает CSS-выход (`data-js`), в 3,4 с измеряет цель и анимирует перелёт
   `x/y/scale`; на узком экране или если цель вне экрана — просто гасит оверлей. Если JS пришёл позже 4,0 с,
   компонент ничего не трогает: иначе погасший оверлей вспыхнул бы снова.
4. Пока интро идёт, анимации первого экрана на паузе, а цель скрыта; после — проявляются.

## Правила показа

Один раз за сессию на версию (`sessionStorage["axis-intro"]` на v1), не при reduced motion, не для `navigator.webdriver`,
не при якоре в адресе. `?intro=blueprint` — показать именно его, `?intro=1` — случайное, `?intro=0` — отключить. Пропуск: кнопка, Esc,
колесо, свайп.

## Где менять

Тайминги — в `components/intro/timeline.ts` и в CSS одновременно. Белые контуры — `room-outline.ts`;
контурная мебель — `python3 scripts/make_furniture_outline.py`. Тесты: `e2e/intro.spec.ts` (обходят
`navigator.webdriver` через `addInitScript`).
