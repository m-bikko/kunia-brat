# Ротация интро

Пять видов интро, случайный при первом визите сессии. Общий движок для v1 и [[soft-landing-v2]].

| Ключ | Название | Пул | Передача |
|---|---|---|---|
| `blueprint` | «Синька» ([[blueprint-intro]]) | v1 | перелёт, точное совпадение на v1 |
| `pop` | «Поп-ап класс»: коробка открывается, класс выпрыгивает по частям | v1, v2 | перелёт |
| `blocks` | «Фигуры-кубики»: части падают и отскакивают на места, «чпок» | v1, v2 | перелёт |
| `pencil` | «Карандаш рисует»: белые линии, потом цвет пятнами | v1, v2 | перелёт |
| `bell` | «Школьный звонок»: волны, затем фон сжимается в круг | v1, v2 | раскрытие без перелёта |

## Как устроено

1. Загрузчик (`intro-boot.tsx`, первым в `<body>`) до первой отрисовки определяет версию по пути (`/v2` в конце),
   решает, играть ли, выбирает вид (`pickIntro`: случайный, не последний показанный) и ставит
   `html[data-intro="play"][data-intro-kind]`. Функции из `lib/intro.ts` сериализуются в скрипт, поэтому они
   самодостаточны (есть юнит-тест на сериализацию).
2. Все сцены пула отрендерены сервером, видна только выбранная. Таймлайны — CSS (`app/styles/intro.css`),
   пружины и отскоки — кривые `linear()` (`--ease-spring`, `--ease-bounce`).
3. `IntroStage` — общий контроллер: пропуск, в 3,4 с перелёт `[data-intro-subject]` в `[data-intro-target]`
   (или конец CSS-раскрытия в 3,65 с), своя страховка; если JS пришёл после 4,0 с — не вмешивается.
4. Мультяшные сцены анимируют части `ClassroomArt` по `[data-part]`; на v2 их класс совпадает с первым экраном
   один в один, на v1 растворяется в чертеже за последние 0,3 с полёта.

## Правила

- Один раз за сессию на версию (`axis-intro` и `axis-intro-v2`), последний вид — в `localStorage` по версии;
  без хранилища интро всё равно играет.
- Не при reduced motion, не для автотестов (`navigator.webdriver`), не при `#якоре`.
- `?intro=<ключ>` — конкретный вид, `?intro=1` — случайный, `?intro=0` — без интро.
- Во время интро страница не прокручивается, анимации первого экрана на паузе.
- Бюджет: разметка всех сцен страницы меньше 80 КБ (тест).
