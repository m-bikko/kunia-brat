# v2 «Мягкая»

Вторая версия лендинга рядом с v1 ([[landing-sections]]) — чтобы сравнивать. Тот же сюжет и порядок блоков, но
мягкий мультяшный язык вместо строгих линий чертежа ([[design-system]]). Адреса `/v2`, `/kk/v2`, `/en/v2`,
закрыта от индексации. Решения владельца — в [[redesign-decisions]].

## Язык

- Цвета (`app/styles/v2.css`): navy #1b2559 основной, brand #3059df на кнопках, sky #dfe8ff, cloud #f4f7ff (фон),
  sun #ffc845 и coral #ff7f66 — только в иллюстрациях и наклейках, не для текста на светлом.
- Форма: карточки 28 px (`rounded-card`), плитки 20 px, поля 14 px, кнопки и чипсы — пилюли. «Наклейка»:
  обводка 2,5 px navy + сплошная тень `shadow-sticker`. Кнопка `softButton` поднимается при наведении и
  опускается при нажатии. Фокус — 3 px brand (на navy — sun), его не перебивает ни одна утилита.
- Шрифт Nunito (`lib/fonts-v2.ts`), грузится только на v2; казахские буквы рисует сам Nunito (проверяет тест).
- Глобальные радиусы v1 равны 0, поэтому в v2 только именованные радиусы.

## Иллюстрации (свои SVG, без людей)

- `ClassroomArt` — класс спереди (640×440): окно, часы, интерактивная панель, шкаф с глобусом, стол учителя,
  шесть парт. Каждая часть — `<g data-part>` (у парт ещё `--i`). Один рисунок служит первому экрану, блоку
  «Как работаем» (стадии 0–3 прячут части через CSS) и трём интро ([[intro-rotation]]).
- `CabinetIcon` — восемь значков-сценок кабинетов на цветных кляксах.
- Декор: `Sparkle`, `Squiggle`, `Dots`; персонажи интро — карандаш и звонок.

## Блоки

Шапка-пилюля (меню телефона — диалог с ловушкой фокуса) → первый экран с классом в «окне» (цель интро) →
этапы на волнистой дорожке → [[order70-tool]] → карточки кабинетов (на телефоне две колонки) → процесс со
сборкой класса → производство (реальные фото в рамках) → факты и бренды → вопросы (один открыт) → G8 →
тёмно-синяя карточка заявки → тёмно-синий подвал. Кнопка WhatsApp прячется над инструментом, как в v1.
