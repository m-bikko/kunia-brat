# AXIS v2 «Мягкая» и ротация интро: дизайн

Статус: на согласовании. Дата: 2026-10-22. Ветка: `feat/landing-v2`.
Основа: v1 «Чертёж» (`docs/superpowers/specs/2026-10-22-blueprint-landing-design.md`), в проде на
https://kuni-brat.vercel.app с исправлениями финального ревью (`8924b66`).

## 1. Цель

1. Вторая версия лендинга рядом с первой, чтобы сравнивать: тот же сюжет и порядок блоков, но мягкий
   мультяшный язык вместо строгих линий чертежа.
2. Четыре новых мультяшных интро и случайная ротация интро на обеих версиях.

## 2. Решения владельца (2026-10-22)

| Вопрос | Решение |
|---|---|
| Где живёт v2 | Рядом с v1: `/v2`, `/kk/v2`, `/en/v2`. v1 остаётся на `/`, `/kk`, `/en` |
| Интро | Сделать все четыре: «Поп-ап класс», «Фигуры-кубики», «Карандаш рисует», «Школьный звонок»; случайно чередовать |
| Пулы ротации | v1: «Синька» + 4 новых. v2: только 4 новых |
| Иллюстрации | Свои SVG, без людей |
| Палитра | Тёмно-синий основной + солнечно-жёлтый и коралловый акценты |
| Дизайн в целом | Утверждён в чате |

## 3. Маршруты и SEO

- `app/(ru)/v2/page.tsx` → `/v2`; `app/(intl)/[locale]/v2/page.tsx` → `/kk/v2`, `/en/v2`. Те же root layout,
  что у v1, `ensureStatic = "navigation"`, страницы пререндерятся статически.
- У v2 `robots: noindex, nofollow`, в `sitemap.xml` её нет, hreflang-альтернатив нет. Заголовок и описание
  страницы те же, что у v1.
- Переключатель языка на v2 ведёт на v2 другого языка (`/v2` ↔ `/kk/v2` ↔ `/en/v2`).
- Внутренние якоря v2 те же, что у v1: `#order70`, `#index`, `#process`, `#contact`. Ссылки на внутренние
  страницы живого сайта — обычный `<a>`, как в v1.
- Видимого переключателя «v1 / v2» нет: версии сравнивают по адресу.

## 4. Интро: общий движок для v1 и v2

### 4.1 Виды и пулы

| Ключ | Название | Пул |
|---|---|---|
| `blueprint` | «Синька» (существующее) | v1 |
| `pop` | «Поп-ап класс» | v1, v2 |
| `blocks` | «Фигуры-кубики» | v1, v2 |
| `pencil` | «Карандаш рисует» | v1, v2 |
| `bell` | «Школьный звонок» | v1, v2 |

### 4.2 Выбор и правила показа

Решает загрузочный скрипт до первой отрисовки (как сейчас `IntroBoot`), один на обе версии:

- Версия определяется по пути: оканчивается на `/v2` → v2, иначе v1.
- Играть или нет — правила v1 без изменений: один раз за сессию, не при reduced motion, не для
  автоматизированного браузера, не при `#якоре`, `?intro=0` выключает. Ключ сессии свой у каждой версии
  (`axis-intro` и `axis-intro-v2`): увиденное интро на v1 не отменяет интро на v2.
- Вид: случайный из пула версии, но не тот, что показывался последним на этой версии (`localStorage`,
  ключ версии; при недоступном хранилище — просто случайный).
- `?intro=1` — запустить случайное; `?intro=<ключ>` — запустить конкретное. Ключ не из пула версии
  трактуется как `?intro=1`.
- Результат: `html[data-intro="play"][data-intro-kind="<ключ>"]`.

### 4.3 Общий контракт времени

Все виды живут в одном таймлайне, чтобы один контроллер и одна страховка обслуживали любой вид:

| Момент | Что происходит |
|---|---|
| 0 — 3,4 с | Основное действие вида (CSS-таймлайн, стартует до гидрации) |
| 3,4 — 4,3 с | Передача: перелёт в иллюстрацию первого экрана или раскрытие (см. 4.5) |
| 4,0 — 4,4 с | CSS-страховка: оверлей гаснет сам, если JS не взял интро на себя |
| 4,4 с | Загрузочный таймер снимает `data-intro` (если JS его не отменил) |

Семантика страховки — как в исправленной v1: контроллер отменяет таймер загрузчика, когда берёт интро на
себя; если JS пришёл после 4,0 с, контроллер не трогает начавшийся CSS-выход.

### 4.4 Поведение, общее для всех видов

- Кнопка «Пропустить интро», Escape, прокрутка колесом или пальцем — пропуск за 0,3 с.
- Пока интро идёт, анимации первого экрана на паузе, цель перелёта скрыта, прокрутка страницы
  заблокирована (`overflow: hidden` + `scrollbar-gutter: stable`, чтобы страница не прыгала).
- Узкий экран (< 1024 px) или цель вне экрана — вместо перелёта оверлей гаснет за 0,5 с.
- Подпись к каждому виду на языке страницы, на всех трёх языках.
- Без JS первый экран читается: страховка гасит оверлей к 4,4 с.

### 4.5 Сценарии новых видов

Все на тёмно-синем фоне (`navy`), рисунки светлые с синими и тёплыми акцентами, движения пружинные
(CSS `linear()`-кривые с перелётом), только `transform`, `opacity` и `stroke-dashoffset`.

- **`pop` «Поп-ап класс».** 0,1 с — выпрыгивает коробка-книжка с логотипом; 0,7 — откидывается крышка;
  1,0 — разворачивается пол; 1,3 — стены «вспрыгивают» с перелётом; 1,7 — парты падают по очереди с
  отскоком; 2,1 — выезжает доска; 2,3 — цветок качается один раз; 3,4 — перелёт.
- **`blocks` «Фигуры-кубики».** 0,1 — 1,2 с — капсулы, круги и скруглённые квадраты падают и отскакивают;
  1,4 — 2,4 — перелетают на свои места и становятся партами, доской, часами и цветком; 2,6 — «чпок»
  (масштаб 1,06 → 1); 3,4 — перелёт.
- **`pencil` «Карандаш рисует».** 0,1 с — влетает карандаш с лицом и моргает; 0,4 — 2,0 — рисует контур
  класса, двигаясь вдоль линии (`offset-path`); 2,0 — 2,6 — цвет заливается мягкими пятнами;
  2,7 — карандаш кланяется и уезжает; 3,4 — перелёт.
- **`bell` «Школьный звонок».** 0,1 с — появляется звонок; 0,4 — 1,4 — качается; 0,6 — 2,2 — расходятся три
  круглые волны; 2,2 — логотип и подпись; 2,8 — 3,6 — круговое раскрытие: оверлей сжимается в круг и
  исчезает, открывая страницу. Перелёта нет.

### 4.6 Передача в первый экран

- Цель — элемент с `data-intro-target` (иллюстрация первого экрана; в v1 атрибут `data-plan-target`
  переименовывается).
- `pop`, `blocks`, `pencil` строят тот же мультяшный класс, что нарисован на первом экране v2: на v2
  перелёт кончается совпадением один в один, как у «Синьки» на v1.
- На v1 мультяшный класс в конце перелёта растворяется в чертеже (кроссфейд за последние 0,3 с полёта).
- «Синька» на v1 работает как сейчас.

### 4.7 Вес

Разметка всех интро пула рендерится на сервере, показывается только выбранная (`display: none` у
остальных). Бюджет — не больше 80 КБ HTML на всё интро страницы (несжатого), проверяется тестом.

## 5. Визуальный язык v2

### 5.1 Цвета

| Токен | Значение | Назначение |
|---|---|---|
| `navy` | #1b2559 | основной: заголовки, текст, обводки, тёмные блоки, фон интро |
| `navy-muted` | #4b5584 | вторичный текст (не светлее: AA на `cloud` и `sky`) |
| `brand` | #3059df | главные кнопки, активные состояния |
| `sky` | #dfe8ff | светло-голубые заливки, фон «окна» иллюстрации |
| `cloud` | #f4f7ff | фон страницы (холодный белый) |
| `surface` | #ffffff | карточки |
| `sun` | #ffc845 | акцент: иллюстрации, наклейки, фокус на тёмном |
| `coral` | #ff7f66 | акцент: иллюстрации, наклейки |
| `ok` | #15803d | только статус «есть» в инструменте |

Жёлтый и коралловый не используются для текста на светлом фоне.

### 5.2 Форма и материал

- Скругления: карточки 28 px, плитки 20 px, поля 14 px; кнопки, чипсы и переключатели — пилюли.
- «Наклейка»: обводка 2,5 px `navy` и сплошная смещённая тень `0 6px 0 navy` (у мелких элементов
  `0 3px 0`). Кнопка при нажатии опускается на 3 px, тень уменьшается.
- Фокус: обводка 3 px `brand` с отступом 3 px; на тёмном — `sun`.
- Глобальные токены радиусов v1 равны 0, поэтому у v2 свои именованные радиусы (`rounded-card` и т. п.);
  v1 не меняется.

### 5.3 Типографика

Nunito через `next/font` (latin, cyrillic, cyrillic-ext): 800–900 для заголовков, 600–700 для текста.
Шрифт подключается только на страницах v2. Казахские буквы (ә ғ қ ң ө ұ ү һ і) должны рисоваться самим
Nunito, без подмены, — проверяется при сборке.

### 5.4 Движение

- Пружины на наведении (карточки: подъём на 4 px и наклон до 1°), «чпок» у галочек, мягкое открытие
  аккордеона, однократное появление блоков при прокрутке.
- Никаких бесконечных покачиваний. При reduced motion — без смещений и масштабов.

### 5.5 Иллюстрации

Свои SVG как React-компоненты (`components/v2/art/`), чтобы части можно было анимировать и красить
токенами. Правила: обводка 2,5 px `navy`, скруглённые концы и углы, плоские заливки из палитры, без
градиентов, без людей.

- Класс первого экрана — слоями: оболочка комнаты, мебель, техника (доска, панель), декор (цветок, часы,
  полка). Эти же слои дают четыре состояния для блока «Как работаем».
- Восемь значков-сценок кабинетов: компьютер, мольберт, швейная машинка, гончарный круг, верстак,
  домбра с книгой (казахский язык), книга (русский язык), облачко «Hello» (английский).
- Декор: звёздочки, точки, волнистые линии.
- Персонажи и предметы интро: коробка с крышкой, фигуры, карандаш с лицом, звонок.

## 7. Общий код

Поведение v1 не меняется; общая логика выносится, чтобы не дублировать её в v2:

- `useOrder70Kit` — вкладки, отметки по кабинетам, сброс текущего кабинета, счётчики, ссылка WhatsApp,
  клавиатура вкладок. Используют инструменты v1 и v2.
- Выбор кабинета → текст сообщения в WhatsApp для блока заявки.
- Контроллер интро (пропуск, перелёт или раскрытие, страховка) — общий для всех видов; «Синька»
  переезжает на него без изменения поведения.
- Чистая функция выбора вида интро (пул, последний показанный, случайное число) — с юнит-тестами.

## 8. Тексты и языки

- Новые строки — во всех трёх словарях: подписи четырёх интро; «Отправить N позиций на расчёт» с формами
  множественного числа; фраза для экранного диктора «Есть N из M» (вместо голых чисел в живом регионе);
  «N позиций по Приказу» на карточках кабинетов; описание иллюстрации первого экрана v2; наклейка
  «Свой цех»; подписи состояний иллюстрации «Как работаем».
- Сообщение WhatsApp получает формы множественного числа (исправляет английское «1 items») — это общая
  строка, улучшение видно и на v1.
- В ru/kk перед тире ` `, в en тире нет.

## 9. Доступность

- Контраст AA для всего текста v2 (проверка `e2e/a11y.spec.ts` распространяется на `/v2`, `/kk/v2`,
  `/en/v2`); видимый фокус у всех кнопок и ссылок-кнопок.
- Декоративные SVG — `aria-hidden`; содержательные (класс первого экрана) — `role="img"` с подписью.
- Галочки — нативные чекбоксы; вкладки — по ARIA-шаблону, как в v1.

## 10. Производительность

- Новых зависимостей нет (motion уже стоит).
- Nunito грузится только на v2. Фото — `next/image`, как в v1.
- Бюджет интро — 80 КБ HTML на страницу (4.7).

## 11. Проверка

- e2e v2: три языка открываются, нет горизонтальной прокрутки на 360 и 390 px, нет ошибок в консоли;
  сценарий инструмента на `/v2`; переключатель языка остаётся на v2; v2 закрыта от индексации и не в
  sitemap.
- e2e интро: каждый вид через `?intro=<ключ>` играет и заканчивается к 4,6 с на обеих версиях; на v2
  никогда не выпадает `blueprint`; два визита подряд не дают один и тот же вид; интро v1 не отменяет интро
  v2 в той же сессии; без JS и при медленном JS — как у исправленной v1; якорь отключает интро;
  прокрутка заблокирована во время интро; бюджет 80 КБ.
- Юнит: выбор вида интро; формы множественного числа для новых строк и сообщения WhatsApp.
- Шрифт: казахские буквы на `/kk/v2` рисует Nunito.
- Весь набор: `pnpm test:py && pnpm test && npx tsc --noEmit && pnpm lint && pnpm test:e2e`, затем сборка
  на Vercel после пуша.
