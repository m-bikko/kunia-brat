# Лендинг AXIS: концепт «Чертёж» + инструмент «Приказ № 70»

Дата: 2026-10-22. Статус: дизайн одобрен заказчиком по частям (структура, визуальный язык, инструмент).

## Зачем

Первая версия редизайна (ветка `feat/landing-redesign`, коммит `4008317`) выглядит как сгенерированная AI:
шаблонный скелет SaaS-лендинга, один приём заголовка «чёрное + синее» на каждой секции, фото как обои под
затемнением, нет идеи, принадлежащей только AXIS.

Новый концепт строится на двух вещах, которые отличают AXIS:
1. **Проектирование.** AXIS означает «ось»; сайт подаётся как архитектурный лист (концепт A «Чертёж»).
2. **Норматив.** Школы оснащают кабинеты по Приказу № 70; лендинг даёт рабочий инструмент подбора по нему (концепт C).

Критерий успеха: заказчик открывает страницу и не узнаёт в ней шаблон; инструмент даёт заявку со списком.

## Что не меняется

- Маршруты и i18n: `/` (ru), `/kk`, `/en`, два root layout, `global-not-found`, редирект `/ru`.
- Слой контента: `content/types.ts` + словари `content/locales/*`, `content/cabinets.ts`, `content/brands.ts`.
  Словари расширяются новыми ключами; три языка обязательны.
- SEO: `buildMetadata`, JSON-LD (Organization, WebSite, FAQPage), sitemap, robots, CSP, аналитика.
- Логотип и синий AXIS `#3059df`.
- Ссылки на страницы старого сайта: обычные `<a>`.

### Движение

Используется `motion/react`; всё уважает `prefers-reduced-motion` через `MotionConfig reducedMotion="user"`;
анимируются только transform, opacity и `stroke-dashoffset`.

- Первый экран: размерные линии плана прорисовываются (inline SVG, `stroke-dashoffset`), выноски появляются по очереди.
- Индекс кабинетов: смена превью при наведении/фокусе строки (crossfade).
- Процесс: сборка изометрического класса по шагам при прокрутке (механика текущей `Process`, новое оформление).
- Инструмент: счётчики и полоса «есть/подобрать» обновляются при отметке.

Удаляются как источники шаблонности: `BorderBeam`, `Marquee`, `AnimatedGridPattern`, `BlurFade`, `NumberTicker`,
`HeroVisual` (слайдшоу), появление каждого блока через blur.

## Интро «Синька» (добавлено по референсу screening-rho.vercel.app)

Задача: захватить внимание на первом экране, как интро референса, где персонаж из ролика «поселяется» в интерфейсе.
Наш сюжет: AXIS — «ось»; кабинет начинается с осей; чертёж-синька проявляется в реальный класс и занимает своё
место на листе первого экрана.

### Сценарий (~4,5 с)

| Время | Что на экране |
|---|---|
| 0.0–0.6 с | Полноэкранный оверлей цвета синьки `#1a3696` с тонкой белой сеткой 48px. В центре появляется знак логотипа: уголок и квадрат. |
| 0.6–1.4 с | Из уголка через весь экран вытягиваются две оси с метками X и Y; внизу моноширинная подпись «Каждый кабинет начинается с оси». |
| 1.4–2.6 с | Белыми линиями прорисовывается изометрический класс (пол, стены, окна, размерные линии), затем пунктиром мебель. |
| 2.6–3.4 с | Фон переходит из синьки в цвет бумаги, контуры сменяются цветными слоями (оболочка, мебель, декор, доска, включённые экраны). |
| 3.4–4.4 с | Класс перелетает в лист «План-схема» первого экрана (измерение позиции и transform, FLIP); оверлей исчезает; строки H1 появляются по очереди. |

### Правила

- Показывается один раз за сессию (`sessionStorage["axis-intro"] = "seen"`). Не показывается при
  `prefers-reduced-motion: reduce` и при `navigator.webdriver` (автотесты и headless-роботы).
  Параметр URL `?intro=1` принудительно показывает интро, `?intro=0` отключает (для проверки).
- Пропуск: кнопка «Пропустить интро» (видима всё время, доступна с клавиатуры), Esc, колесо мыши, свайп.
  При пропуске оверлей уходит за 0,3 с без перелёта.
- Без мигания: разметка оверлея рендерится на сервере и скрыта по умолчанию; блокирующий inline-скрипт в `<head>`
  ставит `html[data-intro="play"]` до первой отрисовки, CSS показывает оверлей только при этом атрибуте и блокирует
  прокрутку. Страховка: CSS-анимация прячет оверлей через 7 с, если JS не загрузился.
- Оверлей `aria-hidden`, кроме кнопки пропуска; контент страницы в DOM доступен поисковикам и скринридерам.
- Только SVG + `motion/react` (`pathLength`, `opacity`, `transform`, цвет фона), без видео и новых зависимостей.
- Контурный слой класса (белые линии) генерируется скриптом из исходного SVG (`room-outline`).
- Тексты в словаре: `intro.caption` (ru «Каждый кабинет начинается с оси», kk «Әр кабинет осьтен басталады»,
  en «Every classroom starts with an axis»), `intro.skip` («Пропустить интро», «Интроны өткізу», «Skip intro»).

## Инструмент «Приказ № 70»

### Данные

- Источник: таблицы «Матрица соответствия» на страницах кабинетов axisgroup.kz, выгружены 2026-10-22
  headless-браузером (таблица рендерится на клиенте).
  Итого 398 позиций: информатика 22, арт 54, швейная 65, гончарная 45, труд 114, казахский 39, русский 30, английский 29.
- Файл `content/order70.ts`, сгенерированный скриптом `scripts/extract-order70.py` из сырой выгрузки
  (`scripts/data/order70-raw.json`, коммитится). Формат:

  ```ts
  interface Order70Item { name: string; unit: string }          // unit: "шт.", "компл.", "набор", ...
  interface Order70Group { category: string; items: Order70Item[] } // category как в источнике
  export const order70: Record<CabinetId, Order70Group[]>;
  export const order70Source: { url: string; retrieved: string };
  ```

- Разбор строки «КАТЕГОРИЯ Название»: ведущая последовательность заглавных (кириллица, включая казахские,
  латиница, цифры, знаки) до первого слова со строчной буквой. Единица — из последней колонки, приводится к нижнему регистру.
- Названия позиций и категорий не переводятся (на всех языках как в источнике); под инструментом строка
  «Перечень приводится по тексту Приказа № 70» на языке страницы.

### Поведение

- Вкладки 8 кабинетов (ARIA tabs, стрелки на клавиатуре); на мобильном горизонтальная прокрутка.
- Список по категориям; у каждой позиции настоящий `<input type="checkbox">` «уже есть в школе» с подписью-названием
  и единицей измерения. Отмеченные — приглушены и зачёркнуты, справа «есть».
- Состояние отметок хранится отдельно для каждого кабинета в состоянии компонента (переключение вкладок не сбрасывает).
- Боковая панель: превью рендера, «Всего / Уже есть / Подобрать», полоса доли «есть», кнопка «Сбросить отметки»,
  основная кнопка «Отправить N позиций на расчёт» (N = подобрать) → WhatsApp.
- Длинный список (> 12 позиций в категории) ограничен по высоте с внутренней прокруткой списка, а не страницы.
- Мобильный: счётчик и кнопка закреплены внизу инструмента (sticky).

### Сообщение в WhatsApp

Шаблон локализован (ключи словаря), пример ru:

```
Здравствуйте! Прошу рассчитать оснащение: {cabinet}.
По Приказу № 70: {total} позиций.
Уже есть в школе ({have}): {haveList}.
Подобрать: {need} позиций.
```

Если ничего не отмечено, строка «Уже есть» заменяется на «Нужен полный комплект». Если сообщение длиннее
1 800 символов, список «уже есть» обрезается с хвостом «и ещё N».
