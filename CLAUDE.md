# AXIS landing (axisgroup.kz)

Лендинг AXIS: оснащение школьных кабинетов под ключ, в двух версиях на общих данных и логике:
v1 «Чертёж» (`/`, `/kk`, `/en`) — страница как набор листов чертежа; v2 «Мягкая» (`/v2`, `/kk/v2`, `/en/v2`) —
мультяшный стиль со скруглениями. Инструмент подбора по Приказу № 70 и случайное интро при первом визите
на обеих. Next.js 16.4 + Tailwind v4 + motion. Обзор и команды — `README.md`.

## Правила проекта

- Тексты только через словари `content/locales/{ru,kk,en}.ts`; новый ключ добавлять во все три (тип `Dictionary` это проверит).
- Крупные заголовки — массивы строк (`Lines`); между строками в разметке нужен пробел `" "`.
- В ru/kk перед тире ставить `\u00a0`. В en тире не использовать.
- v1, язык чертежа: острые углы, линии 1px, синий `brand` — единственный цвет (`ok` только для статуса «есть»).
  Цвета, z-index — только токены из `app/globals.css`.
- v2, мягкий язык: компоненты только в `components/v2/`, токены в `app/styles/v2.css` (navy, sky, cloud, sun,
  coral; `rounded-card/tile/field`, `shadow-sticker`). Кнопки — `softButton`, метки — `Sticker`. Жёлтый и
  коралловый не для текста на светлом. Глобальные радиусы v1 равны 0 — в v2 только именованные.
- v2 noindex и не в sitemap; общую логику брать из `hooks/` и `lib/`, а не копировать из v1.
- Интро: виды и пулы — `lib/intro.ts`; сцена — серверная разметка `.intro-scene[data-kind]` + CSS в
  `app/styles/intro.css`; летящий элемент `[data-intro-subject]`, цель `[data-intro-target]`. Мультяшные сцены
  анимируют `[data-part]` из `ClassroomArt`, а не копию рисунка.
- Любая анимация уважает reduced motion; анимировать только transform, opacity и `stroke-dashoffset`.
- Тайминги интро живут в двух местах: `components/intro/timeline.ts` и `app/styles/intro.css`.
- Данные Приказа № 70 не править руками: `scripts/data/order70-raw.json` → `python3 scripts/extract_order70.py`.
- Ссылки на страницы, которых нет в этом приложении, — обычный `<a>`, не `next/link`.
- После правок `@theme` в `globals.css`: `rm -rf .next` перед сборкой (кэш Turbopack/Tailwind).
- Перед сдачей: `pnpm test:py && pnpm test && npx tsc --noEmit && pnpm lint && pnpm test:e2e`.

## Wiki (База знаний)

В проекте есть LLM-поддерживаемая база знаний в `wiki/`.

**При любых вопросах о проекте:**
1. Сначала прочитай `wiki/index.md` — найди релевантные страницы.
2. Прочитай нужные страницы из `wiki/pages/`.
3. Отвечай, опираясь на вики. Если информации нет — ищи в коде и обновляй вики.

**При изменениях в проекте:**
- Если изменение затрагивает архитектуру, модели данных, интеграции или важные концепции — обнови соответствующие страницы в `wiki/pages/`.
- Обнови `wiki/index.md`, если создана новая страница.
- Добавь запись в `wiki/log.md` (дата, тип операции, затронутые страницы).

**Схема вики:** `wiki/CLAUDE.md`
